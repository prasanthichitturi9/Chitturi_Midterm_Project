# Comparing Three NLP Models

**Course:** Applied Natural Language Processing  
**Project:** Midterm Project – Comparing Three NLP Models

## Project Overview

This project compares three neural language models for character-level next-character prediction using the Tiny Shakespeare dataset.

The models implemented are:

1. Bigram Language Model
2. Long Short-Term Memory (LSTM) Model
3. Small Transformer Model with Causal Self-Attention

The objective is to compare their training performance, validation performance, computational time, and generated text quality.

## Dataset

**Dataset:** Tiny Shakespeare

**Source:** https://github.com/karpathy/char-rnn/blob/master/data/tinyshakespeare/input.txt

- Total characters: 1,115,394
- Vocabulary size: 65 unique characters
- Training split: 90% (1,003,854 characters)
- Validation split: 10% (111,540 characters)
- Batch size: 64
- Context length: 128 characters

The dataset is included in the `data/` folder as `input.txt`.

## Model Implementations

### Bigram Model

The Bigram model predicts the next character using only the immediately preceding character. It provides a simple baseline for comparing more advanced architectures.

### LSTM Model

The LSTM model uses recurrent hidden and cell states to learn contextual relationships across character sequences.

### Transformer Model

The Small Transformer uses token embeddings, positional embeddings, causal self-attention, feedforward layers, and an output layer to predict the next character.

## Experimental Setup

- Programming language: Python
- Framework: PyTorch
- Environment: Google Colab
- Hardware: CUDA GPU
- Training iterations: 2,000 per model
- Evaluation metric: Cross-entropy loss
- Generated text: 500 characters per model

## Experimental Results

| Model | Parameters | Training Loss | Validation Loss | Time (seconds) |
|---|---:|---:|---:|---:|
| Bigram | 4,225 | 2.8835 | 2.9155 | 7.85 |
| LSTM | 946,625 | 1.3012 | 1.5255 | 53.90 |
| Transformer | 826,433 | 1.4106 | 1.6031 | 76.13 |

Execution times include training and periodic evaluation.

## Key Findings

The LSTM achieved the lowest training and validation losses among the three models. The Bigram model completed training in the shortest time but generated the least coherent text.

Both the LSTM and Transformer generated recognizable Shakespeare-style dialogue. However, the Transformer did not outperform the LSTM under the experimental conditions.

The results demonstrate that more advanced architectures do not necessarily achieve better performance with a fixed training configuration.

## How to Run the Project

1. Download or clone this repository.
2. Open `NLP_Midterm.ipynb` in Google Colab.
3. Enable GPU acceleration if available.
4. Ensure the Tiny Shakespeare dataset is available at the path expected by the notebook, or use its dataset download cell.
5. Execute the notebook cells in sequence to preprocess the dataset, train the models, evaluate performance, and generate text.
6. Review the resulting comparison tables, graphs, and generated samples.

Running all training cells will retrain the models and may produce different execution times.

## Conclusion

The experiment demonstrated the limitations of Bigram modeling, the benefits of recurrent memory in LSTM networks, and the role of causal self-attention in Transformer models.

Under the selected training conditions, the LSTM achieved the strongest overall performance, while the Transformer provided a useful alternative approach to character-level language modeling.
